## 2. 不得改变的主要约束

**投资与账户：**现货A股小市值周频策略，约30只；与单一ETF策略共享券商账户但证券完全不重叠；本策略只计算真实划归资金，现金和在途占用不得双重使用。数据同口径时QMT优先，QMT缺失可由已校核的Tushare补充；维护期的Tushare-only研究必须标示临时来源。

**既定研究基线：**400只经济候选池、30买/45保留、统一平均并列百分位、因子包等权、股票目标60%、65%纠偏、单股5%、行业20%、20%预警/25%应急停用与30%回撤筛选。固定起点、成本情景、压力矩阵按01/03/Schema原文执行，不搜索替代参数来“过线”。

**数值与事件：**硬比例门槛的份额/NAV/HWM/回撤采用精确有理数；金额与费用按对应货币舍入合同。证券级与全局禁买由风险模块唯一裁决；撤销等待中真实成交和资源占用持续有效。历史股息税按**股权登记日**选制度，取得与转让交割日确定持有期；晚到事件可重投影派生份额，但不得篡改实际资本流、成交和当时决策。

**执行安全：**FORWARD_MANUAL仅生成清单和导入已确认回报。本任务不授权发送、撤销真实订单，不要求改造整个ETF R5、不增消息总线/审批发布平台，也不允许假设共享现金协调能力已经具备。

## 3. 施工模块与验收顺序

按01的D21次序实施，避免先跑投资曲线再补账本：

1. **公共输入与事实：**Schema校验、身份/单位/时间、数据来源与历史事实选择。
2. **股数现金账户：**唯一账本、公司行动、资本流、精确份额、税费、幂等与断点恢复。先跑固定事件链。
3. **策略决策：**400池、因子包、百分位、30/45缓冲、固定目标金额和FLAT_SCORE边界。
4. **风险和执行：**合并卖出、费后约束、证券级与全局禁买、订单状态机、资源冻结、最小共享现金人工协调。
5. **回测和采用：**日线/分钟因果时间轴、固定起点与S0—S3压力、完整绩效、停用否决和基准评价。
6. **人工前向：**仅在真实能力另经核验后按受限范围生成清单、导入回报和对账，不启用自动报撤单。

每一步使用相同核心规则，交付源代码、可重复测试、人工可读结果和剩余阻断。不以单纯“通过了很多单测”代替关键资金/成交/公司行动链。

## 4. 资料结构与运行核对

压缩包内`小市值周频策略_V5D2/`目录保留**原V5D2完整37个文件**（原设计分册含HTML、Schema、两套Bundle模板、税务TEST_ONLY例、黄金向量、用例清单、参考脚本、校核结果和概要V5）。原内容没有被合并处理修改。

离线自校核（在`小市值周频策略_V5D2/`目录中执行）：

```bash
python verification/verify_design.py
python verification/verify_revision.py
python verification/check_documents.py
```

它们验证局部算术与文档一致性；生产G01—G19用例必须在**新代码入口**独立实现与执行。`golden_vectors.json`不能被直接当成生产代码，不得通过调用oracle模拟器来自证系统通过。

**待补真实输入**仍只有四类：最终因子包及公式、实际分配资金/账户权限与初始状态、真实券商费税清算与委托语义、QMT/Tushare及共享现金能力证据。缺资料可用明示的TEST_ONLY输入开发骨架，但不能将示例升级为VERIFIED、不能宣布投资采用或开真实订单。
